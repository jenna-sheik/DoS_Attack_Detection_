# DoS Attack Detection System

A real-time Denial-of-Service (DoS) attack detection system that uses machine learning to identify and classify malicious network traffic patterns.

##  Technologies Used

- Python
- Scikit-learn / TensorFlow (depending on your model)
- CSE-CIC-IDS2018 Dataset
- Wireshark
- Pandas, NumPy, Matplotlib (for preprocessing and visualization)

##  Features

- Real-time network traffic monitoring
- DoS attack classification using trained ML models
- Alerts/logs for suspicious traffic detection
- Model comparison and evaluation

## ML Models Compared

- Random Forest
- Support Vector Machine (SVM)
- Logistic Regression
- K-Nearest Neighbors (KNN)
- LSTM (chosen for this project)
